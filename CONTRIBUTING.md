# Contributing

Mọi performance claim mới cần:

1. exact hardware/MIG profile, driver, image digest, vLLM/model revision;
2. raw metric definition và aggregation;
3. parent experiment với đúng một thay đổi;
4. correctness evidence;
5. repeated target-hardware measurements và uncertainty;
6. trạng thái `verified`, `contradicted`, `inferred` hoặc `unverified`.

Không commit model weights, contest secrets, evaluator prompts riêng tư hoặc raw
logs chứa dữ liệu nhạy cảm.
