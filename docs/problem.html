ERS NORMALIZATION

TPOT has higher local leverage

Near 47/4, one millisecond TPOT changes score far more than one millisecond TTFT.

Ideas →

Decode cadence, stable batching, graph coverage, CPU gaps.

70 × 6 + POISSON

Serving dynamics dominate a single prompt

Burstiness creates queueing; multi-turn creates state lifetime and possible prefix reuse.

Ideas →

Replay exact arrivals, bucket by turn, active-batch histogram, prefix hit rate.

HYBRID ARCHITECTURE

Two state systems must remain correct

Attention KV and convolution state have different allocation and rollback semantics.

Ideas →

Hybrid cache profiling, ShortConv path, strict speculation correctness gate.

3 vCPU / 8 GB RAM

CPU control plane can gate the GPU

Scheduler, tokenizer, event loop and process pools compete for a small CPU budget.

Ideas →

Systems timeline, run queue, tokenizer A/B, thread/worker isolation.

H200 MIG TARGET

RTX 4080 is a filter, not a verdict

SM89 validates logic and workflow; SM90 MIG decides latency, block size and occupancy.

Ideas →

Two-stage gates: local reject early, target confirm only survivors.

5 SUBMISSIONS / DAY

Information gain is a scarce resource

A bundled build cannot identify which change helped or caused regression.

Ideas →

Known-good control, one-change candidate, replicate, reserve rollback slot.

03 / IDEA PORTFOLIO

Hypotheses có thứ tự

Rank theo expected ERS × probability ÷ cost, rồi giảm hạng theo correctness và integration risk.

P0

Artifact regression caused 63 → 51

Why: twelve points dwarf the reported ~1% fusion gain. Measure: known-good digest versus binary-search overlays. Kill: known-good also scores 51 under stable evaluator.

P1

Decode batches miss efficient CUDA Graph coverage

Why: Poisson arrivals and 70 active conversations create recurring batch sizes. Measure: batch histogram, graph/eager ratio, host gaps, client TPOT. Kill: graph coverage is already high and gaps are outside decode.

P1

Scheduler and prefill budget disturb decode cadence

Why: new turns may preempt or inflate iterations. Measure: TPOT/ITL by active batch and prefill interference. Kill: changes stay inside noise or harm TTFT more than ERS gain.

P2

Multi-turn prefix reuse reduces later-turn TTFT

Why: turns share conversation history. Measure: cached tokens, eviction and TTFT for turns 1–6. Kill: unsupported hybrid path, low hit rate or memory pressure hurts TPOT.

P2

FP8 weight and KV paths have different value

Why: weight bandwidth and cache capacity are separate bottlenecks. Measure: isolated A/Bs for speed, memory and quality. Kill: fallback/dequant path or no capacity pressure.

P3

A measured kernel remains fusion-worthy

Why: only useful if frequent, material and not already compiled/captured. Measure: frequency × duration × removable fraction, then end-to-end A/B. Kill: gain below noise or SM90 register pressure reverses it.

R

Hybrid speculative decoding reaches break-even

Why: potentially large but architecture/version risk is high. Measure: exact outputs, accepted tokens, draft/verify cost and state rollback. Kill: initialization/correctness fails or measured break-even is negative.
