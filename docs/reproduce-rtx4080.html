01 / WINDOWS HOST → WSL2

Chuẩn bị runtime Linux mà không phá driver

vLLM GPU quickstart yêu cầu Linux. Trên Windows, đường thực dụng là WSL2. Driver nằm ở Windows host và được map vào WSL; không cài Linux NVIDIA display driver bên trong WSL.

Host preflight 2026-08-02: máy hiện tại báo RTX 4080 Super, compute capability 8.9, 16,376 MiB, driver 591.86. Python Windows hiện chưa có vLLM/PyTorch/Triton; vì vậy các bước dưới đây tạo Linux environment mới thay vì sửa Python host.

04 / WORKLOAD + RAW TIMESTAMPS

Replay 70 conversations × 6 causal turns

scripts/rtx4080_replay.py tạo 420 Poisson arrivals bằng exponential inter-arrival, nhưng turn N vẫn chờ turn N−1 của cùng conversation. Client parse SSE, lưu submit/first/last timestamp, server usage token count, TTFT, TPOT, status và error thành JSONL.

python scripts/rtx4080_replay.py \
  --model LiquidAI/LFM2.5-1.2B-Instruct \
  --conversations 70 --turns 6 \
  --rate 7 --seed 2025 --max-tokens 64 \
  --aggregate mean \
  --output results/rtx4080/R0-baseline.jsonl

Implementation flow trong replay client

arrival = poisson_arrivals(conversations=70, turns=6, request_rate=7, seed=2025)

if turn > 1:
    await previous_turn_completed.wait()       # preserve conversation causality
await sleep_until(run_start + scheduled_s)    # preserve planned arrival when possible

submitted = perf_counter()
async for sse_line in streamed_response:
    if content_delta:
        first_token = first_token or perf_counter()
        last_token = perf_counter()

ttft_ms = (first_token - submitted) * 1000
tpot_ms = (last_token - first_token) * 1000 / (completion_tokens - 1)

Measurement boundary: đây là client-observed latency, gồm local HTTP/frontend. completion_tokens lấy từ server usage; nếu server không gửi usage, script ghi rõ content_event_fallback. SSE chunk không được giả định luôn bằng một token.

Level 2 — kernel contract trước implementation

def optimized_shortconv(x, state, *, activation, dtype):
    if not supported_shape(x, state) or dtype not in (torch.float16, torch.bfloat16):
        return reference_shortconv(x, state, activation=activation)
    return triton_shortconv(x, state, activation=activation)

# Required matrix before benchmark:
# batch: 1, 2, 8, 32, 70, 128
# dtype: FP16, BF16; odd/tail shapes; contiguous/non-contiguous
# values: zeros, random, large/small magnitude
# state: compare output AND updated recurrent state
torch.testing.assert_close(actual_output, reference_output, rtol=..., atol=...)
torch.testing.assert_close(actual_state, reference_state, rtol=..., atol=...)

Level 3 — benchmark ladder

  1. Correctness matrix trên SM89.
  2. Microbenchmark sau JIT warm-up, report p50 và distribution.
  3. Nsight counters: register pressure, occupancy và HBM/GDDR traffic.
  4. End-to-end R0/K/R0′ bằng 420-request replay.
  5. Retest trên SM90 H200 MIG; autotune config local không được hardcode làm universal default.

Important: VLLM_USE_PRECOMPILED=1 không hợp lệ khi sửa C++/CUDA native code. Với Triton/Python kernel có thể dùng editable path; nếu thay native ABI phải full build đúng hướng dẫn của pinned vLLM.

TROUBLESHOOTING

Các lỗi có khả năng gặp nhất

torch.cuda.is_available() == False

Kiểm tra Windows NVIDIA driver, wsl --update, distro là WSL2 và nvidia-smi trong WSL. Không cài Linux display driver để “sửa”.

OOM khi vLLM capture graph

Hạ utilization/context/capture sizes; thử eager chỉ để phân loại lỗi. Ghi rõ cấu hình nào dùng graph khi so điểm.

Prefix cache crash trên LFM2

Xác nhận pinned source hỗ trợ hybrid cache và dùng --mamba-cache-mode align; nếu option không tồn tại, không copy flag từ docs version khác.

Replay có TPOT = 0 hoặc thiếu token count

Kiểm tra server trả streaming usage. Nếu một SSE event chứa nhiều tokens, fallback event count không đủ để khẳng định evaluator TPOT.

ncu không đọc được counters

Enable NVIDIA GPU Performance Counters ở Windows Control Panel, kiểm tra driver/build requirements và cài Linux x86 Nsight Compute trực tiếp trong WSL2.

Local +1% nhưng target regression

Expected risk: SM89/SM90, GDDR/HBM, CPU budget, graph shapes và MIG isolation khác nhau. Giữ candidate nhưng retune/remeasure target; không average hai máy.
